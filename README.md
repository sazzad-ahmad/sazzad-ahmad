## 🌟 Projects and Repositories

### 🏥 [MediCare - Multi-Branch Cloud Pharmacy Suite](https://github.com/sazzad-ahmad/mediCare-multibranch-suite)
A cloud-native, multi-tenant pharmacy management suite with multi-branch inventory, batch expiry tracking, procurement, stock transfers, role-based access control, and POS checkout.

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **Backend:** PHP 8.2 REST API with PDO, Docker, Render
- **Database:** TiDB Serverless with 13 relational tables
- **Live app:** [medi-care-multibranch-suite.vercel.app](https://medi-care-multibranch-suite.vercel.app)
- **API:** [medicare-multibranch-suite.onrender.com](https://medicare-multibranch-suite.onrender.com)
